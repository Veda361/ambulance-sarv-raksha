# Sarv Raksha - Jhansi Ambulance Project

Sarv Raksha is an emergency medical service and ambulance management system designed for rapid dispatch, real-time tracking, and emergency coordination.

## Status

> **Notice:** This repository is currently in the initial architecture and planning stage. Application features and service implementations have not yet been developed.

## Project Structure

- `docs/` — Architectural designs, requirements, workflows, and API specifications.
- `android/` — Mobile client application for ambulance drivers and emergency responders.
- `backend/` — Server services, APIs, database models, and dispatch routing.
- `web/` — Web portals for dispatchers, hospital coordination, and administrative dashboards.

## Next Steps

1. Finalize system requirements and ambulance dispatch workflows in `docs/`.
2. Determine technology stack for backend, web, and mobile clients.
3. Establish database schema and API contracts.
